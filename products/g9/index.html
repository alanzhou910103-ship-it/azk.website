2.4GHz 1000Hz Wireless Performance

In 2.4GHz wireless mode, the G9 supports up to 1000Hz polling for more responsive input in compatible games. Bluetooth 5.3, 2.4GHz wireless, and USB-C wired connections give distributors a practical tri-mode product story for multiple user setups.

The controller is compatible with Switch 2, Switch, PC, iOS, and Android devices. Switch 2 compatibility is for gameplay only; the controller does not support console wake-up. Functions may vary by platform, game, and connection mode.

Hall Effect Precision and Six-Axis Motion

The G9 uses Hall Effect joystick technology, with contactless sensing designed to support accurate input and drift-resistant performance during long gaming sessions.

Six-axis motion sensing adds motion-based control in compatible games, while four adjustable levels of asymmetric dual-motor vibration provide selectable in-game feedback.

Custom Controls and RGB Identity

Programmable rear buttons help players place selected commands within easier reach. Turbo mode supports rapid repeated inputs for compatible games.

RGB lighting offers gradient, breathing, and fixed-light modes with colour, brightness, and speed adjustment. Mode memory retains the selected lighting setting after use.

Built for Longer Sessions

A 600mAh rechargeable battery is rated for more than 12 hours of play under supplier test conditions, with actual endurance varying by use and lighting settings. Typical charging time is about 2-3 hours.

The wireless receiver is available as an optional accessory and is not included as standard.
